# Boston Housing Price Prediction

## Overview
This project focuses on analyzing and predicting housing prices using the Boston Housing Dataset.  
The notebook includes data preprocessing, exploratory data analysis (EDA), visualization, and machine learning model implementation.

## Dataset Features

- CRIM  → Per capita crime rate by town
- ZN → Residential land zoned for large lots
- INDUS → Non-retail business acres proportion
- CHAS → Charles River dummy variable
- NOX → Nitric oxide concentration
- RM → Average number of rooms per dwelling
- AGE → Proportion of old owner-occupied units
- DIS → Distance to employment centers
- RAD → Accessibility to highways
- TAX → Property tax rate
- PTRATIO → Pupil-teacher ratio
- B → Proportion related feature
- LSTAT → Lower status population percentage
- MEDV → Median house value
